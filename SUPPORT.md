# Support

QwenPaw-Data is pre-1.0, community-supported software intended for local-first,
single-user deployments.

## Where to ask

- Use [GitHub Discussions](https://github.com/agentscope-ai/QwenPaw-Data/discussions)
  for setup questions, usage help, and design discussions.
- Use [GitHub Issues](https://github.com/agentscope-ai/QwenPaw-Data/issues) for
  reproducible bugs and scoped feature requests.
- Follow [`SECURITY.md`](SECURITY.md) for vulnerabilities. Never disclose a
  security issue or credential in a public issue or discussion.

Please include the QwenPaw Data version or commit, operating system, Python and
Node.js versions, workspace backend, sanitized `qwenpaw-data doctor` output, and the
smallest reproducible example. Remove API keys, passwords, private URLs, and
business data from logs before posting.

## Version policy

Only the latest release line receives fixes before 1.0. Minor releases may
contain breaking changes; patch releases are intended to remain compatible
within a minor line. Supported platform and dependency versions are listed in
[`docs/COMPATIBILITY.md`](docs/COMPATIBILITY.md).

Community support is best-effort and has no response-time SLA. Maintainers may
close reports that cannot be reproduced, apply to unsupported versions, or lack
the requested diagnostics.
