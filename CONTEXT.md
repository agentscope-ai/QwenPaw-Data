# QwenPaw Data editions

These terms distinguish shared product behavior from choices made for the open-source distribution.

## Language

**Internal baseline**: The reviewed internal revision from which an OSS release takes its shared product behavior. It is a specific revision, not whatever happens to be newest.

**OSS adapter**: The part of the open-source distribution that fits shared behavior to a local installation. It is not a second implementation of that behavior.

**Local identity**: The owner of a single-user installation's sessions, settings and scheduled work. A person does not need to sign in for that ownership to exist.
_Avoid_: Anonymous user.

**Legacy store candidate**: A location consistent with a previous release's storage layout. Finding one does not establish what it contains or whether anyone has migrated it.
