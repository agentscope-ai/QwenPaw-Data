# 分区与查询策略

根据表后缀确定分区字段和 WHERE 写法，结合表类型确定查询范围。

---

## 后缀 → 分区字段 → WHERE 写法

| 表后缀 | 分区字段 | 数据语义 | WHERE 写法 |
|--------|----------|----------|----------|
| `_df` | `ds` | 每个分区为当期完整快照 | `ds = MAX_PT(...)` 或 `ds BETWEEN ...` |
| `_di` | `ds` | 每个分区为当期新增/变更 | `ds BETWEEN '{start}' AND '{end}'` |
| `_hh` | `ds` + `hh` | 每个分区为该小时完整快照 | `ds = '{date}' AND hh = '{hour}'` |
| `_hi` | `ds` + `hh` | 每个分区为该小时新增/变更 | `ds = '{date}' AND hh BETWEEN '{h1}' AND '{h2}'` |

`ds` 格式取决于表的时间粒度：日级为 `yyyyMMdd`，月级为 `yyyyMM`。分钟刷新表额外具备 `mm` 字段。

---

## 查询约束

1. **所有表必须分区过滤** — WHERE 中必须出现分区键，否则触发全表扫描
2. **DWD 表数据量极大**（一行 = 一次事件）— 必须将分区范围控制在尽可能小的范围内，绝对禁止无分区条件查询
3. **DWS 表已按维度聚合**，数据量适中 — 单分区或连续多天分区均可
4. **DIM 表为实体属性**，数据量小 — 通常 `ds = MAX_PT(...)` 取最新快照
5. **ADS 表为场景预聚合**，数据量最小 — 直接 `ds = MAX_PT(...)` 取最新结果
6. **多分区键表逐级过滤** — 有 `ds` + `hh` 的表，两个分区键都要出现在 WHERE 中
