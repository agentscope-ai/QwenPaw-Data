# 常见的用户意图歧义问题以及解决方法

本文档记录了几类用户意图中常见的歧义问题，若遇到此类问题，应抛出问题以及待确定的选项，让用户确认。

## 1. 分析指标指向不明

用户提出的数据分析问题中指标指向不明确，存在多个可选指标符合数据分析需求。例如，用户提出对“留存率”指标分析，数据中可用指标包括“访问留存率”、“使用留存率”等。

**解决方法**：抛出问题以及待确定的选项（即，所有可用指标），让用户确认。

## 2. 指标聚合粒度不明

用户提出的数据分析问题中指标聚合粒度不明确，存在多个可选聚合粒度符合数据分析需求。例如，用户需要计算一段时间的对话用户数，聚合粒度可以是“日均对话用户数”、“该时间段内对话用户数总和”。

**解决方法**：考虑以下几种情况：

- 在 BI 场景中，计算一段时间内的 xx 人数/次数等统计值，聚合粒度默认为日均值，如，“对话用户数 -> 日均对话用户数”

- 在 BI 场景中，计算环比/同比等指标时，基础数据聚合粒度默认为均值。如计算对话次数月环比，使用“该时间段内日均对话次数”作为计算对话次数月环比的基础数据。

- 在 BI 场景中，计算一段时间内的比例/率值类指标时，按分子、分母所用的基础数据类型区分默认聚合方式：

  - **基于用户数计算的比例指标**（如渗透率 = 对话用户数 / 访问用户数）：默认**先计算每天的比例值，再对这些每日比例取一段时间的日均值**，而**不是**先把分子、分母的用户数各自取日均（或求和）后再相除。如计算一段时间的对话渗透率，应先算出每天的渗透率（每日对话用户数 / 每日访问用户数），再对这些每日渗透率求日均值，而非用“日均对话用户数 / 日均访问用户数”得到结果。

  - **基于使用次数、时长等数值计算的比例指标**（如点赞率 = 点赞次数 / 对话次数）：默认**先对一段时间内的次数、时长等基础数值分别求和，再用总和相除得到比例**，而不是逐日求比例再取均值。如计算一段时间的点赞率，应为“该时间段点赞次数总和 / 该时间段对话次数总和”。

如不被上述情况覆盖，则抛出指标聚合粒度的歧义问题以及所有可用聚合粒度，让用户确认。
