# 常见数据来源歧义问题以及解决方法

本文档记录了几类数据来源中常见的歧义问题，若遇到此类问题，应抛出问题以及待确定的选项，让用户确认。

## 1. 多个可用数据表的选择不明

数据中多个数据表在指标计算、数据维度选择等都满足数据分析需求。例如，分析“计算某产品不同端 dau 指标”，表 `xxx_index` 和 `xxx_distribution` 都包含可用于计算 dau 指标都数据，且包含指向不同端的字段，即两张表都可用于数据分析。

**解决方法**：

1. 在多张表满足数据分析要求的情况下，根据每张表的描述，选择最符合数据分析需求的数据表。

2. 参考 [`references/table-naming.md`](references/table-naming.md) 中的表命名规范，选择最符合数据分析需求的数据表：
    - 根据 [`references/table-naming.md`](references/table-naming.md) 中定义的表类型，选择最符合数据分析需求的数据表类型。
    - 根据表前缀，定位 [`references/table-naming.md`](references/table-naming.md) 中对应的表命名结构。根据表命名结果理解表的特征与用途。由此，选择最符合数据分析需求的数据表。

3. 优先考虑能够最准确计算指标的数据表组合，而不是优先考虑能够计算某一“代理指标”的数据表。
