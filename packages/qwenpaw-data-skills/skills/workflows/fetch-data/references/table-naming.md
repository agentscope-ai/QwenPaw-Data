# 表命名规范

数仓表名命名结构，供选表时解码使用。

## 表类型

表前缀通常定义了表的类型，以及表的特征。

| 表类型        | 前缀     | 表的特征                                     | 适用条件                                             |
| ------------- | -------- | -------------------------------------------- | ---------------------------------------------------- |
| 贴源层（ODS） | `s_`   | 源系统原样同步，未经清洗加工                 | 极少直接查询，仅当上层表均不满足且需要原始数据时使用 |
| 应用层（ADS） | `ads_` | 面向具体场景，指标+维度均已预聚合            | 需求与已有场景表完全匹配，无需二次加工               |
| 汇总表（DWS） | `dws_` | 已按维度聚合沉淀指标（如"每天每应用的 DAU"） | 需要汇总指标 + 维度切片分析                          |
| 明细表（DWD） | `dwd_` | 一行 = 一次业务事件（如一次 API 调用）       | 需要事件级明细（漏斗/留存），或需自定义口径聚合      |
| 维度表（DIM） | `dim_` | 存储实体属性（如用户名称、模型类型）         | DWD/DWS 表缺维度属性时，JOIN 维度表补充              |

---

## 贴源层（ODS）命名结构

```
s_{源系统表名}[_{变体后缀}]
```

| 变体     | 命名规则                  | 含义                    |
| -------- | ------------------------- | ----------------------- |
| 标准全量 | `s_{表名}`              | 贴源全量同步            |
| 天增量   | `s_{表名}_delta`        | 每天增量同步            |
| 小时全量 | `s_{表名}_hh`           | 每小时全量同步          |
| 小时增量 | `s_{表名}_delta_hh`     | 每小时增量同步          |
| 临时表   | `tmp_{输出表名}_{序号}` | 中间过程表，序号从0开始 |

> **命名冲突规则**：不同源系统同步到同一 project 下出现表名重复时，后进表追加源系统应用名，如 `s_{表名}_{应用名}_delta`。

## 维度表（DIM）命名结构

```
dim_{BU}_{维度定义}[_{标签}]
```

- **BU**：业务线缩写，或 `pub`（公共，跨BU共用，如时间维度）
- **维度定义**：`user`、`model` 等
- **标签**（可选）：自定义命名标签

示例：

- `dim_{BU}_model_usage_unit` → {BU} · 模型计量单位维表
- `dim_{BU}_product_spec` → {BU} · 商品规格表
- `dim_{BU}_biz_user_info` → {BU} · 用户信息表
- `dim_pub_calendar` → 公共 · 时间维度表

## 明细表（DWD）命名结构

```
dwd_{BU}_{数据域}_{业务过程}[_{标签}]_{刷新周期}{增量全量}
```

- **BU**：业务线缩写，或 `pub`（表示数据包含多BU）
- **数据域**：`log`、`trd`、`biz` 等
- **业务过程**：`ord`、`clk`、`page`、`exp` 等
- **标签**（可选）：自定义命名标签
- **刷新周期**：`d`(天)、`h`/`hh`(小时)、`mi`(分钟)
- **增量全量**：`i`=增量、`f`=全量

示例：

- `dwd_{BU}_log_http_api_call_di` → {BU} · 日志域 · HTTP API调用 · 天增量
- `dwd_{BU}_biz_order_payment_df` → {BU} · 业务域 · 订单支付 · 天全量
- `dwd_{BU}_trd_click_event_hi` → {BU} · 交易域 · 点击事件 · 小时增量

## 汇总表（DWS）命名结构

```
dws_{BU}_{数据域}_{数据粒度}[_{标签}]_{统计周期}[_{刷新周期}][_{增量全量}]
```

- **BU**：业务线缩写，或 `pub`
- **数据域**：`log`、`user` 等，可含子域（如 `log_sub`）
- **数据粒度**：可多个，`aid`、`userdim`、`appdim` 等
- **标签**（可选）：`overview`、`core` 等
- **统计周期**：`1d`、`7d`、`30d` 等（指标覆盖时间窗）
- **刷新周期**（可选）：`d`(天)、`h`(小时)
- **增量全量**（可选）：`i`=增量、`f`=全量

示例：

- `dws_{BU}_user_appdim_overview_1d` → {BU} · 用户域 · 应用维度粒度 · 大盘概览 · 最近1天
- `dws_{BU}_log_userdim_core_1d_df` → {BU} · 日志域 · 用户粒度 · 核心 · 最近1天 · 天全量快照
- `dws_{BU}_trd_orderdim_revenue_7d` → {BU} · 交易域 · 订单粒度 · 收入 · 最近7天

## 应用层（ADS）命名结构

```
ads_{BU}_{应用名称}[_{数据粒度}][_{标签}]_{统计时间周期}
```

- **BU**：业务线缩写，或 `pub`
- **应用名称**：`dashboard`、`report`、`monitor` 等
- **数据粒度**（可选）：`aid`、`userdim` 等，可多个
- **标签**（可选）：自定义命名标签
- **统计时间周期**：`d`、`1d`、`7d`、`30d` 等

示例：

- `ads_{BU}_dashboard_overview_1d` → {BU} · 仪表盘 · 大盘概览 · 最近1天
- `ads_{BU}_report_userdim_core_7d` → {BU} · 报表 · 用户维度 · 核心 · 最近7天

## 命名段常见取值

### 数据域缩写

| 缩写         | 含义   |
| ------------ | ------ |
| `user`     | 用户   |
| `model`    | 模型   |
| `frontend` | 前端   |
| `active`   | 活跃   |
| `overview` | 大盘   |
| `log`      | 日志域 |
| `trd`      | 交易域 |
| `biz`      | 业务域 |
| `mgt`      | 管理域 |
